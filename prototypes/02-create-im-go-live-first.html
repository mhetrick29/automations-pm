⚠️ Design note — v1 vs v2 feedback:
  • v1 (this): "Is this an outage?" → if No, pick a reason. Simple, ships first.
  • v2: If it's not an outage, follow up with "Did Brain create the incident at the right severity? If not, why?" — reasons could reuse the same taxonomy (impact not big enough, impact not correct, duplicate, etc.)
  • v3+: Expand to cover the full set of Brain actions — was the comms template right? Was the scope correct? Did Brain link the right signals? Each action Brain takes becomes a feedback surface.
